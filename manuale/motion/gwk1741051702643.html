MC_SetCamTableEndPointIndex

The MC_SetCamTableEndPointIndex instruction changes the end point index of the cam table that is specified in an in-out parameter.

Although the operation performed on the cam table and the result obtained from it are the same as those of the MC_SetCamTableProperty instruction, it allows you to adjust the task period required from the execution to completion of the instruction.

Function

  • This instruction updates the latest cam table and then outputs the end point index and the maximum number of cam data.

  • Although the operation performed on the cam table and the result obtained from it are the same as those of the MC_SetCamTableProperty instruction, it allows you to adjust the task period required from the start to completion of the instruction by specifying the number of cam data to search per period of the primary periodic task when searching the end point of the cam data in order from the start point.

  • For details on the basic function of this instruction, refer to ☆MC_SetCamTableProperty.

  • When 10 is specified for SearchNum (Number of Searches), the instruction will be completed at the same timing as when the MC_SetCamTableProperty instruction is used.

For details on cam tables, refer to the NJ/NX-series CPU Unit Motion Control User’s Manual (Cat. No. W507) or NY-series Industrial Panel PC / Industrial Box PC Motion Control User’s Manual (Cat. No. W559).

use:

  • When searching the cam table, an error will occur if the phases are not in ascending order before the 0 phase is found.

  • You cannot change the maximum number of cam data from the user program.

  • Execute this instruction after changing the end point in the cam data or overwriting values in the cam data.

    If the end point index is changed or the phases are not in ascending order, the cam operation and the operation of the EndOfProfile (End of Cam Cycle) of the MC_CamIn (Start Cam Operation) instruction may not be as expected.

  • If the cam table is changed while this instruction is being processed, the update process will not be performed correctly. Wait for execution of this instruction to be completed before you change the cam data from the user program.

  • Cam data variables are global variables. You can therefore access or change the values of cam data variables from more than one task. If you change the values of cam data variables from more than one task, program the changes so that there is no race condition in writing the value from more than one task.

  • If you use exclusive control of global variables between tasks for a cam data variable, do not use the cam data variable for motion control instructions while exclusive control is in effect for the cam data variable. An Incorrect Cam Table Specification error (error code: 5439 hex) will occur.

  • Increasing the value of SearchNum (Number of Searches) increases the task execution time of the primary periodic task, which may cause the task period to be exceeded. When you set the value of SearchNum, increase the value in steps starting from a small value while confirming that the task period is not exceeded.

  • If you execute an instruction that uses the processing target cam table while this instruction is being processed, an unintended execution result may occur. Make sure that this instruction is completed before you execute an instruction that uses the cam table.

Instruction Details

This section describes the execution time of this instruction.

Refer to ☆MC_SetCamTableProperty for details on how this instruction updates the end point index of a cam table.

The execution time of this instruction can be calculated as follows.

  • When the EndPointIndex does not point to the end of the cam data structure array

    Execution time of this instruction [task period] = RoundUp( EndPointIndex / SearchNum )

  • When EndPointIndex points to the end of the cam data structure array

    Execution time of this instruction [task period] = RoundUp( (EndPointIndex - 1) / SearchNum )

Note that RoundUp rounds up fractions to the nearest whole number.

For example, if 5 is specified for SearchNum in a cam table as shown below, the execution time of this instruction will be 2 task periods.

The search for the end point will be executed as many as the SearchNum (Number of Searches) for each task period, starting from MyCam1 [2]. The end point is the data located one cam data before the first cam data with a phase of 0 after the start point in the cam table, so the instruction searches up to MyCam1 [11] and finds EndPointIndex.

Re-execution of Motion Control Instructions

This instruction cannot be re-executed.

A Motion Control Instruction Re-execution Disabled error (error code: 543B hex) occurs if re-execution is attempted.

Multi-execution of Motion Control Instructions

Execution during Execution of Other Instructions

Multi-execution of this instruction is not allowed if the following instructions that use the same CamTable as that in this instruction have already been executed.

  • MC_SaveCamTable instruction

  • MC_SetCamTableProperty instruction

  • MC_SetCamTableEndPointIndex instruction

  • MC_GenerateCamTable instruction

Execution of Other Instructions during Instruction Execution

Multi-execution of the following instructions that use the same CamTable is not allowed during execution of this Instruction.

  • MC_SaveCamTable instruction

  • MC_SetCamTableProperty instruction

  • MC_SetCamTableEndPointIndex instruction

  • MC_GenerateCamTable instruction

Error

If an error occurs during instruction execution, Error will change to TRUE.

You can find out the cause of the error by referring to the value output by ErrorID (Error Code).
