MC_GearInPos2

The MC_GearInPos2 instruction performs electronic gearelectronic gear operation for the specified gear ratio between the master axis and the slave axis.

The positions at which to start synchronizing the master axis and slave axis are specified.

This instruction is a partially modified version of the MC_GearInPos (Positioning Gear Operation) instruction. For differences from the MC_GearInPos (Positioning Gear Operation) instruction, refer to ☆MC_GearInPos2 in ☆MC_GearInPos2.

Function

Differences from the MC_GearInPos (Positioning Gear Operation) Instruction

The operating specifications of this instruction differ from those of the MC_GearInPos (Positioning Gear Operation) instruction. Depending on the application, select which instruction to use.

use:

The catching operation until the slave axis enters the InGear phase differs from the MC_GearInPos (Positioning Gear Operation) instruction. When you replace the MC_GearInPos (Positioning Gear Operation) instruction with this instruction, adjust the input variables and check the operation sufficiently before use.

The following describes the differences between the MC_GearInPos (Positioning Gear Operation) instruction and this instruction.

Whether the Instruction Can Be Executed at Master Axis Zero Velocity

The MC_GearInPos (Positioning Gear Operation) instruction cannot be executed when the master axis velocity is 0 at instruction execution. If it is executed, a Positioning Gear Master Axis Zero Velocity error (error code: 5476 hex) occurs.

This instruction can be executed only when the master axis velocity is 0 and the master axis position is outside the MasterStartDistance range. If it is executed when the master axis velocity is 0 and the master axis position is within the MasterStartDistance range, a “Position Gear Master Axis Zero Velocity error (error code: 5476 hex)” occurs.

memo:

Master axis velocity represents the velocity calculated from the amount of change in the master axis position selected in ReferenceType (Position Type Selection).

Whether the Instruction Can Be Executed at Slave Axis Zero Velocity

The MC_GearInPos (Positioning Gear Operation) instruction generates an error if the slave axis velocity is not 0 at the time of execution. In a state where the slave axis is moving due to another instruction, you must stop the slave axis once before executing the MC_GearInPos (Positioning Gear Operation) instruction.

This instruction can be executed even when the slave axis velocity is not 0. Multi-execution of this instruction enables smooth transition of movements and reduces the wait time between operations.

The MC_GearInPos (Positioning Gear Operation) instruction causes acceleration and deceleration immediately before reaching the sync position. This may result in velocity overshooting or undershooting at the sync position.

If it is possible to provide a sufficient constant velocity section before the sync position, this instruction can improve the occurrence of overshooting and undershooting at the sync position.

Function of This Instruction

  • The MC_GearInPos2 instruction performs gear operation for the slave axis specified with Slave (Slave Axis). The following parameters are also specified: RatioNumerator (Gear Ratio Numerator), RatioDenominator (Gear Ratio Denominator), ReferenceType (Position Type), Acceleration (Acceleration Rate), and Deceleration (Deceleration Rate).

  • For Master (Master Axis), you can specify the command position, actual position, or most recent command position.



  • After operation starts, the Slave (Slave Axis) accelerates and decelerates in sync with the Master (Master Axis) in the catching operation.

  • The slave axis is in the waiting phase until it starts catching operation, in the catching phase until it reaches the slave axis sync position, and in the InSync phase after it reaches the slave axis sync position. The position of the slave axis is synchronized with the master axis during the catching phase and InSync phase.

    The position where the slave axis starts catching is determined by the value of the MasterStartDistance (Master Following Distance) input variable, the master axis position at instruction execution, and the travel direction of the master axis.

    The following describes how this instruction works in two cases, when the value of the MasterStartDistance (Master Following Distance) input variable is not 0 and when it is 0.

    1. When MasterStartDistance is not 0

      Within MasterStartDistance range

      Outside MasterStartDistance range

      Toward MasterSyncPosition

      The slave axis enters the catching phase simultaneously with instruction execution.

      The slave axis enters the catching phase when it moves into the MasterStartDistance range, regardless of the travel direction of the master axis at instruction execution.

      Away from MasterSyncPosition

    2. When MasterStartDistance is 0

      When the travel direction of the master axis at instruction execution is toward MasterSyncPosition, the slave axis enters the catching phase simultaneously with instruction execution.

      When the travel direction of the master axis at instruction execution is away from MasterSyncPosition, the slave axis enters the catching phase when the master axis reaches the master axis position at instruction execution after reversing direction. (This is the same as Figure 2 above.)

  • The Velocity (Target Velocity) input variable is the target velocity for the catching phase.

  • If multi-execution of this instruction is performed while the slave axis is in motion, during the waiting phase, the slave axis continues operation at the velocity and direction before the multi-execution.

    If the master axis velocity is 0 when the catching operation starts, an error occurs.

  • If the direction of the slave axis velocity at the start of the catching operation differs from the direction of the slave axis velocity at the sync position and reversing the slave axis is necessary, but Slave axis reversing not possible is specified in SyncMode (Sync Mode), an error will occur.

  • If the master axis velocity changes significantly, the slave axis velocity will not be constant.

  • If the gear ratio is positive, Slave (Slave Axis) and Master (Master Axis) move in the same direction.



  • If the gear ratio is negative, Slave (Slave Axis) and Master (Master Axis) move in the opposite directions.



  • The MC Function Module calculates the velocity profile for linear acceleration and deceleration with the following three velocities using the Acceleration (Acceleration Rate) and Deceleration (Deceleration Rate).

    1. The velocity of the Slave (Slave Axis) when an instruction is executed is the initial velocity.

    2. The velocity of the Master (Master Axis) at the start of the catching operation multiplied by the gear ratio is the final velocity.

    3. The Velocity (Target Velocity) is the target velocity.

    If the travel distance during the catching phase is too short, the target velocity will not be reached.



    For the Slave (Slave Axis) to catch up with the Master (Master Axis) for the MasterSyncPosition (Master Sync Position) and SlaveSyncPosition (Slave Sync Position), the following condition must be met for the Velocity (Target Velocity).

    When _mcCommand or _mcLatestCommand is set Use the command current velocity.

  • If the initial velocity exceeds the Velocity (Target Velocity) value, a Position Gear Value Error (error code 5475 hex) will occur.

  • When the Count Mode of the master axis is Rotary Mode, you can specify a MasterSyncPosition (Master Sync Position) outside the range specified by the modulo maximum position and modulo minimum position setting values. If you do, the relationship between the master axis current position and the master axis sync position will be the same as when _mcNoDirection (No direction) is specified for Direction in the MC_MoveAbsolute (Absolute Positioning) instruction. use:

  • Refer to ☆Precautions for Master and Auxiliary Axes in Synchronized Control for precautions on the master axis.

  • This instruction calculates the slave axis command assuming that the master axis velocity does not change from the start of the catching operation. Therefore, if the master axis velocity changes during the catching phase, the velocity, acceleration rate, or deceleration rate input to this instruction may be exceeded. Make adjustments so that the catching operation starts only after the master axis velocity has become constant.

ReferenceType (Position Type Selection)

You can select one of the following position types.

  • _mcCommand: Command position (value calculated in the previous task period)

    The master axis command position that was calculated in the previous task period is used for the current period.

    The command value that was calculated for the master axis in the last periodic task is used to calculate the command position of the slave axis in the current period.

  • _mcFeedback: Value obtained in the same task period

    The actual position of the master axis that was obtained in the same task period is used.

  • _mcLatestCommand: Command position (value calculated in the same task period)

    The command position of the master axis that was calculated in the same task period is used.

    This enables the use of information that is more recent than for _mcCommand. However, the axis number of the master axis must be set lower than the axis number of the slave axis.

    If the axis number of the slave axis is lower than the axis number of the master axis, Error will change to TRUE. A Master/Slave Axis Numbers Not in Ascending Order error (error code: 5438 hex) will be output to ErrorID.

use:

Here, the task period is the primary period if the task is the primary periodic task and the task period of the priority-5 periodic task if the task is the priority-5 periodic task. In the same way, the periodic task is the primary periodic task or the priority-5 periodic task.

memo:

The command position that is calculated in the same task period enables greater precision in synchronization than the command position that was calculated in the previous task period.

However, the axis number set for the Master (Master Axis) in the system-defined variable for motion control must be lower than the axis number set for the Slave (Slave Axis) in the system-defined variable for motion control.

Re-execution of Motion Control Instructions

You cannot re-execute motion control instructions.

A Motion Control Instruction Re-execution Disabled error (error code: 543B hex) occurs if re-execution is attempted.

Multi-execution of Motion Control Instructions

The axis command status of the master axis, including whether it is stopped due to an error or it is decelerating to a stop, does not affect the execution of this instruction.

For details on multi-execution of motion control instructions, refer to the NJ/NX-series CPU Unit Motion Control User’s Manual (Cat. No. W507).

Execution during Execution of Other Instructions

You can switch to this instruction or buffer this instruction if you execute it during execution of another instruction.

You can buffer one instruction per axis.

During execution of this instruction, multi-execution of the MC_GearInPos (Position-Specified Gear Operation) instruction cannot be performed.

Multiple execution of this instruction is possible during execution of the MC_GearInPos (Positioning Gear Operation) instruction.

Errors

If an error occurs during execution of this instruction, Error will change to TRUE.

You can find out the cause of the error by referring to the value output by ErrorID (Error Code).



The slave axis is not affected by the error status of the master axis during synchronized control. After the error status of the master axis is cleared, the slave axis continues electronic gear operation when the master axis operates.

The master axis is not affected if an error occurs for the slave axis at or during execution of this instruction.
