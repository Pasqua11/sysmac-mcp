Precautions for Correct Use

  • Observe the following precautions if you use this instruction in a ladder diagram.

    1. Use this instruction only in functions and function blocks. If you use it in a program, a building error will occur.
    2. Always connect this instruction directly to the left bus bar.
  • Before you execute this instruction, set the return value, output variables, and ENO value of the POU.
  • If you use this instruction too often, the flow of processing will be difficult to understand. Use it with caution.
  • Refer to the instruction ☆RETURN in the ST Statement Instructions for a description of the RETURN instruction for the ST program and inline ST.
