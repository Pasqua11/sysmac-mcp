Function

The GetNTPStatus instruction reads the NTP status.

The following information is read: ExecTime (NTP last normal operation time) and ExecNormal (NTP normal end flag).

Precautions for Correct Use

  • Return value Out is not used when this instruction is used in ST.

  • This instruction reads the contents of the _EIP_NTPResult system-defined variable. You cannot access this variable directly. Always use this instruction to read the contents of the variable.
