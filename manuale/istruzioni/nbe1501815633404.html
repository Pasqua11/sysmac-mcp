StringToAry

The StringToAry instruction converts a text string to a BYTE array.

Function

The StringToAry instruction processes the character codes in text string In as numeric values, and assigns each numeric value to the corresponding element of the BYTE array, AryOut[].

The number of converted bytes is stored in Out.

Precautions for Correct Use

  • The NULL character at the end of In is not stored in AryOut[].

  • If the In text string contains only NULL characters, the value of Out will be 0 and AryOut[] will not change.

  • An error will occur in the following case. ENO will be FALSE, and Out and AryOut[] will not change.

    1. The number of bytes in In is larger than the number of elements in AryOut[].
