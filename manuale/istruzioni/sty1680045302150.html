StringMD5

Converts a text string to the MD5 hash value.

Instruction Name

FB/

FUN

 Graphic expression ST expression
StringMD5 (Convert String to MD5)StringMD5 Convert String to MD5Convert String to MD5 FUN

Out:=StringMD5(In);
use: An N502 CPU Unit with unit version 1.63 or later and Sysmac Studio version 1.55 or higher are required to use this instruction.

Function

This instruction converts the text string from the beginning character to the first NULL character of text string to convert In to the MD5 hash value. The converted result is output to return value Out.

A NULL character is not included in the conversion of the MD5 hash value.

33 bytes (32 characters plus NULL) including NULL are output to return value Out.

Precautions for Correct Use

An error will occur if the text string of In does not end with a NULL character. ENO will be FALSE, and Out will not change.
